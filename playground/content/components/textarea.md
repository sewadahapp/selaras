## Props

| Prop | Type | Default |
| --- | --- | --- |
| `modelValue` | `string` | - |
| `placeholder` | `string` | - |
| `rows` | `number` | `3` |
| `size` | `'sm' \| 'md' \| 'lg'` | `md` |
| `disabled` | `boolean` | `false` |
| `invalid` | `boolean` | `false` |
| `ui` | `Partial<Record<'base', string \| object>>` | - |
