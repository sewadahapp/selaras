# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers building Vue and Nuxt interfaces with Selaras, and people preparing documentation, presentations or other material that identifies the library.

## Product Purpose

The repository's documentation explains component APIs, shows working examples and demonstrates customization. The design-kit page provides the approved brand assets and guidance for using them consistently.

## Capabilities and Constraints

The docs use the local Selaras package and the reusable documentation layer. The primary navigation is Overview, Components, Composites, Blocks and Utilities. Blocks provides complete interface examples with responsive previews and source, built from the library's components and composites. Public assets and links must work when deployed under a base URL. Documentation supports light and dark modes and three theme presets.

## Brand Commitments

The name Selaras evokes alignment, harmony and tuning. The user selected Seirama: three bands following a shared curve. Preserve the approved regular geometry and the dedicated small-size artwork. Keep the documentation logo responsive to the active theme colour.

## Evidence on Hand

Approved vectors, PNG exports, lockups, browser icons, typography licence and usage guidance are in the documentation's brand asset kit. The reference requested for the new page establishes a brand asset gallery, palette and typography structure. Do not invent a logo timeline, endorsements, or a design-tool document that does not exist.
