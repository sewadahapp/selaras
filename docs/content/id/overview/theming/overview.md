Selaras memisahkan token CSS semantik, style komponen, dan default perilaku. Anda dapat mengubah beberapa nilai atau menyediakan sistem desain lengkap.

| Tujuan | Panduan |
| --- | --- |
| Ubah permukaan, tipografi, radius, atau bayangan | [Token CSS](/overview/theming/css-tokens) |
| Sesuaikan warna semantik atau daftarkan role | [Role warna](/overview/theming/color-roles) |
| Ikut tampilan sistem atau ubah terang/gelap | [Mode warna](/overview/theming/color-modes) |
| Style satu komponen atau slot | [Penyesuaian komponen](/overview/theming/component-styling) |
| Bagikan style dan default di seluruh aplikasi | [Konfigurasi global](/overview/theming/global-configuration) |
| Style subtree secara mandiri | [Tema scoped](/overview/theming/scoped-themes) |
| Sediakan setiap input tema sendiri | [Tema lengkap](/overview/theming/complete-themes) |

Mulai dari impor CSS agregat di [Instalasi](/overview/getting-started/installation). Ini menyediakan tema default. Untuk tema yang dimiliki sepenuhnya, entry struktural mempertahankan perilaku komponen dan binding sementara Anda menyediakan kontrak tema.

Preset Pelog, Slendro, dan Degung di dokumentasi mendemonstrasikan CSS dan konfigurasi komponen yang bekerja sama. Mereka adalah tema showcase dokumentasi, bukan tema bernama tambahan yang diinstal secara otomatis ke aplikasi Anda.
