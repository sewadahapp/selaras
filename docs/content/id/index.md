Selaras adalah pustaka komponen Nuxt-first yang dibangun di atas Reka UI, Tailwind CSS v4,
dan properti kustom CSS.

Selaras menyediakan komponen yang dapat diakses, kontrak tema semantik, integrasi Nuxt yang diberi tipe,
dan composable untuk UI tingkat aplikasi.

Mulai dari [Pengenalan](/overview/getting-started/introduction), lalu ikuti
[Instalasi](/overview/getting-started/installation) dan [Tema](/overview/theming/overview).
