# Documentation localization

The Selaras docs site supports English (default) and Bahasa Indonesia. English
is the source of truth: Indonesian pages are translations of the English page
at the same path.

## URLs and language selection

English pages remain at the root URL. Indonesian pages use an `/id/` prefix;
for example, `/components/elements/button/` and
`/id/components/elements/button/`. English remains the source of truth;
Indonesian Markdown lives under `docs/content/id/`.

- The active locale is stored in the `selaras-docs-locale` cookie.
- On a first visit, `@nuxtjs/i18n` negotiates the browser language and falls
  back to English.
- The language switcher moves to the corresponding locale-specific route.
- `html lang` and `og:locale` follow the active locale. Translated pages have
  locale-specific canonical URLs and reciprocal `hreflang` alternates.
- An untranslated `/id/` page shows an English fallback notice, canonicalizes
  to its English route, is marked `noindex`, and is omitted from the sitemap.

The static build generates explicit English and `/id/` routes. The locale
cookie is used only for root-language detection and is updated by the language
switcher. The locale-specific route determines the rendered content.

## Content layout

English lives at the content root; translations live in a folder named after
the locale code:

```text
docs/content/
├── components/elements/button.md      # English (default)
├── components/elements/.navigation.yml
└── id/
    └── components/elements/button.md  # Bahasa Indonesia
```

The `docs` collection in `packages/docs/content.config.ts` registers the locale
folder as a separate source. `useDocsPageContent()` removes the `/id` route
prefix before looking up English, then checks `/id/<path>` for a translation.
It falls back to the English page when no translation exists.

The navigation tree always mirrors the English structure. Translated pages
contribute their own frontmatter titles; untranslated entries keep the English
title. Navigation metadata keeps the English paths; runtime links add the
active locale prefix automatically, so do not hardcode `/id` into page links.

## Adding a translation

1. Copy the English Markdown file to `docs/content/id/<same path>.md`.
2. Translate the frontmatter `title` and `description`, and the body prose.
3. Keep code snippets, component names, props, file paths, and links
   unchanged; they must stay technically accurate.
4. Use a consistent Indonesian vocabulary for technical terms.
5. If the English page has a folder `.navigation.yml`, copy it only when its
   labels or order need localizing; otherwise the English metadata applies.

Example frontmatter:

```yaml
---
title: Tombol
description: Tombol aksi dengan varian, ukuran, ikon, dan status pemuatan.
---
```

## UI copy

Chrome strings (navigation labels, search, skip link, error and empty states,
the fallback note, the language switcher) live in
`packages/docs/app/utils/docs-messages.ts`, with English and Indonesian
defaults. Sites can override any string per locale through
`app.config.selarasDocs.messages`:

```ts
export default defineAppConfig({
  selarasDocs: {
    messages: {
      id: { searchDocumentation: 'Telusuri dokumentasi' },
    },
  },
})
```

The published docs layer reads the locale through `useDocsLocale()`, which
reads the `@nuxtjs/i18n` runtime when it exists and otherwise falls back to the
configured default. The layer itself must not import the i18n module.

## Verification

```bash
bun run test                     # unit tests, including locale path and message parity
bun run docs:prepare
bun run docs:build
bun run test:docs-seo            # canonical, sitemap, robots output
```

Manual checks after a build:

- Switch to Bahasa Indonesia on a translated page: the URL must gain `/id`.
- Switch back to English: the `/id` prefix must be removed.
- Open an untranslated Indonesian page directly: English content plus the
  fallback note, English canonical URL, and `noindex`.
- Reload: the cookie keeps the chosen language.
- Inspect `<html lang>` and `og:locale` in both modes.
