# Brand asset exports

The PNG files are transparent rasterizations of the approved SVG masters in this directory, using librsvg through FFmpeg. Symbols are 1024 px square. Lockups are 1200 px wide with their vector aspect ratios preserved. Primary violet uses the palette's sRGB equivalent, #4E40C9. No generated imagery or third-party stock assets are used.

The downloadable archive contains the same artwork, additional icon sizes, vector PDFs and usage guidance. Plus Jakarta Sans lettering is outlined in the SVG files; its licence is included.
